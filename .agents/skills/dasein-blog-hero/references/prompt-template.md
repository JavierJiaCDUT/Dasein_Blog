# Imagegen Prompt Template

Use this only when photography, complex illustration, realistic material, or another non-deterministic raster visual is necessary.

```text
Use case: <photorealistic-natural|stylized-concept|infographic-diagram>
Asset type: 2:1 editorial blog hero for Dasein_Blog
Primary request: <one-sentence visual thesis derived from the complete article>
Subject: <single subject or visual relationship>
Style/medium: restrained editorial <photography|illustration|diagram>, original and intellectually rigorous
Composition/framing: exact 2:1 landscape; keep all essential content inside the central 86% width; strong negative space; compatible with a 12:7 centered card crop
Color palette: near-black, off-white, dark gray, and one article-specific accent color
Text (verbatim): <list exact short strings, or state no text>
Typography: modern grotesk sans serif, high legibility, no more than three levels
Constraints: render listed text verbatim; no invented copy; no unrelated logos; no watermark; no imitation of the source organization's official design
Avoid: generic AI brain, humanoid robot, code rain, glowing network, chat screenshot, decorative clutter, gradients, unnecessary 3D
```

## Prompt construction rules

1. Quote every exact string.
2. Spell unusual names when accuracy needs reinforcement.
3. Include the intended blog-card thumbnail use.
4. State which content must remain in the safe area.
5. Use one accent color.
6. Do not ask imagegen to reproduce an existing organization's design.
7. After the first output, make only one targeted change per iteration.
